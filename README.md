# 桐榮祭2026 運営管理

GitHub Pagesで動作する、メンバー表・買い出しリスト・会計簿の管理ページです。

## できること

- Googleフォームの回答スプレッドシートをCSV形式でダウンロードし、メンバー表として読み込み
- 名前入りメンバー一覧（名前・メール検索、出欠による絞り込み、一覧から氏名や連絡事項を直接編集）
- メンバーの出欠・連絡事項の編集、手動追加、CSV書き出し
- 買う予定／買ったものの管理
- 購入済み品目の実支出を会計簿に自動反映
- その他の支出の手入力、会計CSVの書き出し
- スマホのカメラ／画像からレシートを文字認識し、店名・金額・日付を確認して会計に登録（OCR結果の確認・修正が必要）
- 予算の変更、全データのJSONバックアップと復元

## 使い方

1. Googleフォームの「回答」タブから回答スプレッドシートを開きます。
2. スプレッドシートで「ファイル」→「ダウンロード」→「カンマ区切り形式（.csv）」を選びます。
3. 管理ページの「メンバー表」でCSVを選び、読み込み方法を指定して読み込みます。
4. 「買い出し」で品目・数量・予定額などを登録します。
5. 購入したら「購入済みにする」を押し、実際の合計金額を入力します。会計簿に自動反映されます。
6. 「設定・保存」から定期的にJSONバックアップを書き出してください。

## 保存に関する重要事項

このバージョンはサーバーやGoogleスプレッドシートに書き戻さず、ブラウザの localStorage にデータを保存します。そのため、**同じブラウザ・同じ端末でのみデータが引き継がれ、他のメンバーや端末とは自動共有されません**。ブラウザのデータ削除でも消える可能性があるため、バックアップを保管してください。

Googleフォームの回答はCSVを読み込んだ時点の内容です。フォームの新しい回答を反映するには、CSVを再度ダウンロードして読み込んでください。「置き換える」は現在のメンバー表を上書きします。「追加」は既存のメールアドレスと一致する回答を追加しません。

## 公開

GitHubリポジトリの Settings → Pages で公開元が main ブランチ / root に設定されていれば、GitHub Pagesからアクセスできます。
